# 💰 Bank Loan Analysis

**Data Analysis & Business Intelligence Project**

Comprehensive analysis of bank loan data to understand lending patterns, risk factors, and key performance metrics.

---

## 📋 Project Objective

The main goal of this project is to analyze historical loan data to:
- Evaluate overall loan performance
- Identify good vs bad loans
- Understand repayment trends and risk factors
- Provide actionable insights for better lending decisions

---

## 📊 Key Insights

- **Total Loan Applications**: **18,214**
- **Total Funded Amount**: **$232.46 Million**
- **Total Amount Received**: **$253.80 Million**
- **Good Loan Rate**: **85.45%**
- **Bad Loan Rate** (Charged Off): **14.55%**
- **Average Interest Rate**: **12.50%**
- **Average DTI (Debt-to-Income)**: **14.48%**
